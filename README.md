# Avatar: The Last Airbender

## My Favorite Series

**Avatar: The Last Airbender** is an *animated fantasy adventure series* created by **Michael Dante DiMartino** and **Bryan Konietzko**. It follows Aang, the last Airbender, who must master all four elements to stop the Fire Nation and restore balance to the world.

---

## Quick Facts

| Detail | Information |
|--------|-------------|
| Creators | Michael Dante DiMartino, Bryan Konietzko |
| Original Run | February 21, 2005 - July 19, 2008 |
| Genre | Animation / Fantasy / Adventure |
| Episodes | 61 (3 Books) |
| Music | Jeremy Zuckerman, Benjamin Wynn |

## Main Cast

1. Zach Tyler Eisen as Aang
2. Mae Whitman as Katara
3. Jack De Sena as Sokka
4. Dante Basco as Zuko
5. Jessie Flower as Toph

## Why I Love It

- Memorable and well-developed characters
- Amazing world-building and animation
- Strong themes about friendship and responsibility
  - Aang's journey to master all four elements
  - Zuko's redemption arc
